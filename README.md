# SOTA Models for Segmentation on Different Datasets

This repository contains evaluations of State-Of-The-Art (SOTA) segmentation models on various datasets:

- **BRISC 2025**: Contains notebooks for evaluating models like CATNet, H2Former, MedSAM, MambaUNet, Seg-Mamba, Swin-UNet, Trans-UNet, UCTransNet, UNet, and VM-UNet.
- **BraTS2021 2D Slices**: Contains notebooks for evaluating similar models on the BraTS2021 dataset.
- **LGG Brain MRI**: Contains notebooks for evaluating these SOTA models on the LGG Brain MRI dataset.

## Models Evaluated
- CATNet
- H2Former
- MedSAM
- MambaUNet (MambaNet)
- SegMamba
- Swin-UNet
- TransUNet
- UCTransNet
- UNet
- VM-UNet

## Usage
Each folder contains Jupyter notebooks (.ipynb) corresponding to the evaluation of a specific model on that dataset.
